Este es un trabajo de investigación correspondiente a la cátedra de Inglés Técnico II de mis carreras en curso, Analista en Sistemas de Computación y Licenciatura en Sistemas de Información. Si bien este trabajo es de ámbito académico, lo tratare con cierta **informalidad** en este medio para centrarme en una forma de documentar de manera casual los avances que se hagan en el trabajo.

El propósito de este trabajo es el **estudio de un grafo ponderado de distancias léxicas mediante aplicaciones de algoritmos de grafos**. Se usa como base la **distancia de Levenshtein** para calcular las distancias entre palabras; se estudian ciertas palabras elementales en todos los lenguajes y se comparan mediante levenshtein para abstraer dichas comparaciones a un grafo.

**El enfoque de este trabajo es computacional**, por lo que el interés radica en la propia abstracción de la información en esta estructura de datos y en la aplicación de algoritmos para estudiar el comportamiento de este grafo. Cuestiones lingüísticas soportan el contexto en el que se desarrolla el trabajo, más son de interés secundario para lo que se quiere estudiar.
