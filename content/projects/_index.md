Trabajos y experimentos. Cada carpeta es un **proyecto**: el `_index.md` es la presentación y los `.md` de al lado son entradas (avances, notas, conclusiones).

Para crear uno:

```bash
hugo new projects/mi-proyecto/_index.md
hugo new projects/mi-proyecto/primera-entrada.md
```
